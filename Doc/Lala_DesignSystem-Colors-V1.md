## 1. ที่มาของโทน

แบรนด์ใช้ **navy เป็นสีหลัก + ทองเป็น accent** วางบน**พื้นครีมอุ่น** (ไม่ใช่เทา/ขาว) โทนอุ่นของพื้นและเงาเป็นสิ่งที่ตั้งใจคงไว้ตอนเปลี่ยนพาเลตต์ — navy เข้ามาแทนน้ำเงินกลางเดิม (`#2f7fbf`) เพื่อให้ดูน่าเชื่อถือขึ้น และทองถูกยกจาก 4 สเต็ปกระจัดกระจายขึ้นมาเป็นไล่สีเต็ม เพราะกลายเป็น accent ระดับหนึ่ง

**แหล่งความจริงเดียว (single source of truth)** คือ `@theme` ใน:
- `apps/web-admin/src/app/globals.css`
- `apps/liff-app/src/app/globals.css`

ทั้งสองไฟล์ต้องมีค่าตรงกัน **ยกเว้น** 2 อย่างที่มีแค่ web-admin: ไล่สี `--color-line-*` และ `--brand-mark`

## 2. ไล่สีคงที่ (fixed ramps)

ไล่สีเหล่านี้ **ไม่สลับตามธีม** ค่าเท่าเดิมทั้ง light และ dark

### 2.1 `brand-*` — navy (สีหลัก)

| step | hex | ใช้ทำอะไร |
|---|---|---|
| 50 | `#eff4fa` | พื้น hover อ่อน, ไทล์ไอคอน |
| 100 | `#dbe7f4` | พื้นชิป (avatar circle, badge ขั้นตอน) |
| 200 | `#b8cde8` | เส้นขอบ hover |
| 300 | `#8bacd6` | ink บนพื้นเข้ม (ผ่าน `--brand-ink` ในธีม dark) |
| 400 | `#5183b8` | ต้นทาง gradient แบรนด์มาร์ก |
| **500** | **`#2a5f9e`** | **ปุ่มหลัก, บาร์, เส้นขอบ focus** |
| 600 | `#204b80` | ปุ่มหลัก hover, ink บนพื้นสว่าง |
| 700 | `#183a64` | ink เข้ม, กรอบอุปกรณ์ในมอคอัพ |
| 800 | `#122d4d` | — |
| 900 | `#0d2038` | **ตัวหนังสือบนพื้นทอง** |

### 2.2 `gold-*` — ทอง (accent)

| step | hex | ใช้ทำอะไร |
|---|---|---|
| 50–200 | `#fdf9ea` `#fdf3d4` `#fae5a4` | พื้นอ่อนมาก |
| 300 | `#f7d670` | ตัวหนังสือ active บน navy (10.9:1) |
| 400 | `#f4cb4f` | ปุ่มทอง hover, คำเน้นในหัวเรื่องบน navy |
| **500** | **`#f2c53d`** | **พื้นปุ่ม CTA บน navy, avatar, เส้นคาด, ปลาย gradient** |
| 600 | `#d9a81f` | — |
| 700 | `#b0850f` | **ตัวหนังสือทองบนพื้นสว่าง (ต่ำกว่านี้ไม่ผ่าน)** |
| 800 | `#8a5a06` | ink ทองเข้ม |
| 900 | `#5e3d05` | — |

> ⚠️ **กฎสำคัญที่สุดของทอง — ทองเป็น "พื้น" ไม่ใช่ "หมึก"**
> `gold-500` รับตัวหนังสือ navy ได้ที่ **10:1** แต่รับตัวหนังสือขาวได้แค่ **1.7:1**
> - ตัวหนังสือบนพื้นทอง → ต้องเป็น `text-brand-900`
> - ตัวหนังสือสีทองบนพื้นสว่าง → ต้องเริ่มจาก `gold-700` ขึ้นไป

### 2.3 `clay-500` / `sage-500` — สีสำรองของกราฟ

`#c67139` และ `#7a8a5e` — ใช้เป็นซีรีส์ที่ 3 และ 4 ในชาร์ตเท่านั้น (`SERIES_COLORS` ใน `components/ui/Charts.tsx`) **ห้ามใช้สื่อสถานะของ UI**

ลำดับซีรีส์ชาร์ต: `brand-500` → `gold-500` → `clay-500` → `sage-500`

### 2.4 `line-*` — เขียว LINE (web-admin เท่านั้น)

**ไม่ใช่สีแบรนด์ LaLa'** ใช้ได้แค่ 2 กรณี:
1. UI ที่**วาดหน้าจอของ LINE จริง ๆ** — ปัจจุบันมีที่เดียวคือ `components/landing/LinePreview.tsx`
2. ปุ่มที่เป็น **LINE action จริง** (เช่น เข้าสู่ระบบด้วย LINE)

หน้า landing page เคยใช้เขียว LINE ทั้งหน้า (CTA, แสงเบลอ, ไอคอน, ป้ายแพ็กเกจ, ลิงก์ฟุตเตอร์) ทำให้ผลิตภัณฑ์อ่านเป็น "แบรนด์เขียว" ทั้งที่ chrome ของแอปเป็น navy — ตอนนี้ย้ายเป็น navy+gold หมดแล้ว **อย่าเอาเขียวกลับไปใส่หน้า marketing**

## 3. โทเคนที่สลับตามธีม (`:root` ↔ `.dark`)

ชื่อเหมือนกันทั้งสองธีม ค่าต่างกัน — **ใช้ชื่อพวกนี้ ไม่ใช่ hex หรือ step ของไล่สี**

### 3.1 พื้นผิวและตัวหนังสือ

| token | light | dark |
|---|---|---|
| `bg` | `#f1e8db` ครีมอุ่น | `#14120f` |
| `bg-elev` | `#faf5ed` | `#1b1815` |
| `surface` | `#fdfaf5` | `#221e1a` |
| `surface-2` | `#f6efe4` | `#2a2521` |
| `ink` / `ink-2` / `ink-3` | `#221e1a` / `#5d564c` / `#8a8175` | `#f3ece0` / `#b6ab9b` / `#8a8175` |
| `hairline` / `hairline-strong` | ดำโปร่ง 10% / 20% | ครีมโปร่ง 10% / 22% |

ธีม dark ยัง**คงความอุ่น**ไว้ (charcoal อมน้ำตาล ไม่ใช่เทาน้ำเงิน) เพื่อให้ต่อเนื่องกับพื้นครีมของ light

### 3.2 `brand-ink` — ตัวหนังสือสีแบรนด์

| token | light | dark |
|---|---|---|
| `brand-ink` | `#204b80` (= brand-600) | `#8bacd6` (= brand-300) |
| `brand-ink-strong` | `#183a64` (= brand-700) | `#b8cde8` (= brand-200) |

> ⚠️ **นี่คือกับดักที่เคยทำให้ contrast พัง**
> ไล่สี `brand-*` เป็นค่าคงที่ สลับตามธีมไม่ได้ ถ้าเอา `text-brand-600` ไปวางบนพื้นที่สลับธีม พอพื้นกลายเป็นสีเข้ม จะได้ **1.9:1** (fail) ส่วน `brand-ink` ในธีม dark ได้ **7.1:1** (pass)

**แยกให้ถูก:**

| สถานการณ์ | ใช้ |
|---|---|
| ตัวหนังสือสีแบรนด์บนพื้นธีม (`bg`, `surface`, การ์ด) | `text-brand-ink` / hover `text-brand-ink-strong` |
| พื้น, เส้นขอบ, gradient | ไล่สีดิบ (`bg-brand-500`, `border-brand-200`) |
| ตัวหนังสือบนชิปสีคงที่ (`bg-brand-50` / `bg-brand-100`) | ไล่สีดิบ (`text-brand-600` / `text-brand-700`) — ชิปพวกนี้สว่างทั้งสองธีม จึงไม่มีปัญหา |

### 3.3 โทเคนสถานะ

แต่ละสถานะมี 3 ตัว: `X` (พื้นทึบ/จุด/donut), `X-bg` (พื้นชิป), `X-fg` (ตัวหนังสือบนชิป — และใช้เป็นตัวหนังสือบนพื้นธีมได้ด้วยเพราะสลับตามธีม)

| สถานะ | hue | light (`X` / `-bg` / `-fg`) | ความหมาย |
|---|---|---|---|
| `pending` | ~36° | `#d9880f` / `#fce8c4` / `#8a5205` | รออนุมัติ |
| `approved` | — | `#5b9146` / `#e7f2de` / `#3d6b33` | อนุมัติแล้ว |
| `rejected` | ~5° | `#c0453b` / `#fbe6e3` / `#8f2f28` | ปฏิเสธ + ปุ่มทำลาย |
| `risk` | ~18° | `#cd6a3a` / `#fbe2d4` / `#8a3f16` | เกินโควตา (LWOP) |
| `info` | navy | `#2a5f9e` / `#dbe7f4` / `#183a64` | ข้อมูลกลาง |
| `quiet` | — | `#a19786` / `#efe8dc` / `#5d564c` | ลดความสำคัญ, ยกเลิกแล้ว |

พิเศษ: `rejected-hover` (`#a63a31` light / `#d1504a` dark) — hover ของปุ่มทำลาย ซึ่งเป็นพื้นทึบสถานะเดียวที่กดได้

> ⚠️ **ระยะ hue ต้องห่างกัน — รวมถึงห่างจากทอง**
> `gold ~47° · pending ~36° · risk ~18° · rejected ~5°`
> เดิม `pending` อยู่ที่ ~44° ใกล้ทองเกินไป ชิป "รออนุมัติ" จึงอ่านเป็น accent ของแบรนด์ ไม่ใช่สถานะ ตอนขยับ pending ไปทางส้มต้องขยับ `risk` ตามด้วย ไม่งั้นไปชนกันเอง — **ถ้าจะขยับสถานะไหน ต้องตรวจระยะกับเพื่อนบ้านทั้งสองข้างและกับทอง**

### 3.4 Sidebar — navy ทั้งสองธีม

`sidebar` เป็น navy เข้มทั้ง light (`#12253f`) และ dark (`#0b1626`) ดังนั้น**สเกลตัวหนังสือของมันอยู่นอกการสลับธีม**:

| token | ค่า |
|---|---|
| `sidebar-ink` | ครีม 94% |
| `sidebar-ink-2` | ครีม 68% |
| `sidebar-ink-3` | ครีม 50% |
| `sidebar-line` | ครีม 10% (เส้นคั่น) |

ใช้โทเคนพวกนี้ทุกครั้งที่วางตัวหนังสือบนพื้น navy — **ห้ามฝัง `rgba(250,245,237,…)` ดิบ**

> ⚠️ **active state บน sidebar ต้องเป็นทอง ไม่ใช่ navy**
> `bg-brand-500/15 text-brand-300` เคยใช้ตอน sidebar เป็นน้ำตาลเข้ม พอ sidebar เป็น navy กลายเป็น navy-บน-navy มองไม่เห็น → เปลี่ยนเป็น `bg-gold-500/15 text-gold-300` (10.9:1)

### 3.5 `brand-mark` (web-admin เท่านั้น)

gradient `brand-400 → gold-500` ใช้เป็น**ของตกแต่งเท่านั้น** — ปัจจุบันมีที่เดียวคือไทล์โลโก้ใน `AppShell`

> ⚠️ **ห้ามวางตัวหนังสือทับ gradient นี้** ตัวหนังสือขาวบนปลายทองได้ ~1.7:1
> ตอนเปลี่ยนพาเลตต์ต้องรื้อ gradient นี้ออกจากทุกที่ที่มีตัวหนังสือ: header ของ LIFF (→ แถบ navy + เส้นคาดทอง), ปุ่ม CTA หลัก (→ navy ทึบ), avatar ใน sidebar (→ วงกลมทองอักษร navy)

## 4. กฎที่ห้ามแหก

### 4.1 ห้ามใช้สี default ของ Tailwind

`red-*`, `amber-*`, `emerald-*`, `teal-*`, `indigo-*`, `rose-*`, `slate-*`, `gray-*` ฯลฯ **ต้องเป็น 0 จุดใน `apps/`**

ตรวจได้ด้วย:

```bash
grep -rnE '(bg|text|border|from|to|ring|accent)-(red|amber|yellow|orange|emerald|teal|indigo|sky|cyan|rose|violet|purple|blue|green|slate|gray|zinc)-[0-9]' --include=*.tsx apps/
```

ถ้าเจอ ให้แมปไปโทเคน semantic เช่น `text-red-600` → `text-rejected-fg`, `bg-amber-50` → `bg-pending-bg`

**ทำไมสำคัญ:** สี default ไม่สลับตามธีมและไม่เข้ากับโทนอุ่นของพื้น เวลาเปลี่ยนพาเลตต์รอบหน้ามันจะค้างอยู่เป็นจุดสีหลุดโทน

### 4.2 ตั้งชื่อ map ตาม "เจตนา" ไม่ใช่ "ชื่อสี"

```tsx
// ❌ ผิด — พอเปลี่ยนพาเลตต์ต้องตามแก้ทุก call site
const ACCENT = { teal: "...", indigo: "...", amber: "...", red: "..." };
<StatCard accent="teal" />

// ✅ ถูก
const ACCENT = { info: "...", quiet: "...", pending: "...", risk: "..." };
<StatCard accent="info" />
```

### 4.3 อย่ามีโทเคนสองตัวที่เรนเดอร์เหมือนกัน

หลังเปลี่ยนเป็น navy `brand` กับ `info` กลายเป็นสีเดียวกัน แล้วชิปที่ใช้ `bg-brand-50` ก็ต่างจาก `bg-info-bg` แค่ "ซีดกว่า" จนอ่านไม่ออกว่าเป็นชิป — ต้องตัดตัวที่ซ้ำออก ไม่ใช่เก็บไว้ทั้งคู่

## 5. เช็คลิสต์ตอนเพิ่ม UI ใหม่

1. ตัวหนังสือสีแบรนด์บนการ์ด/พื้น → `text-brand-ink` **ไม่ใช่** `text-brand-600`
2. ตัวหนังสือบนพื้นทอง → `text-brand-900`
3. ตัวหนังสือบนพื้น navy → `text-sidebar-ink*`
4. สถานะ → โทเคน `pending`/`approved`/`rejected`/`risk`/`quiet` ไม่ใช่สี Tailwind
5. ปุ่มทำลาย → `bg-rejected hover:bg-rejected-hover`
6. ห้ามวางตัวหนังสือบน gradient navy→ทอง
7. เปิด `.dark` ทดสอบด้วย (หน้า `/super-admin` บังคับ dark อยู่แล้ว ใช้ตรวจได้)
8. รัน grep ข้อ 4.1 ก่อน commit

## 6. ข้อจำกัดที่รู้อยู่

- **ยังไม่มี theme toggle** — `.dark` เข้าถึงได้จริงแค่หน้า `/super-admin` ที่ hardcode `className="dark"` โทเคน dark ของหน้าอื่นถูกตรวจด้วยการบังคับใส่คลาสผ่าน DevTools แล้ว แต่จะเห็นจริงเมื่อมี toggle
- **ชิป `bg-brand-50` / `bg-brand-100` เป็นชิปสว่างในธีม dark ด้วย** — อ่านได้ แต่ดูสว่างโดดบนการ์ดมืด ถ้าจะแก้ต้องทำเป็นโทเคนที่สลับธีม (ยังไม่ทำ)
- **`gold-600` และ `gold-900` ยังไม่มีที่ใช้ในโค้ด** — เก็บไว้ให้ไล่สีครบ ส่วนสเต็ปอื่นมีที่ใช้จริงทั้งหมด
